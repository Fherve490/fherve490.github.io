Conditions d'utilisation

Dernière mise à jour : 27 octobre 2026

1. Objet

FAM$ est un outil personnel. Son propriétaire l'utilise pour déposer des vidéos dans la boîte de réception de ses propres comptes TikTok, avec l'API TikTok Content Posting.

2. Utilisateurs

Seul le propriétaire de FAM$ utilise l'outil, et seulement pour les comptes TikTok dont il est titulaire. Il n'existe aucune inscription publique.

3. Fonctionnement

FAM$ demande uniquement l'autorisation video.upload, avec user.info.basic que TikTok ajoute d'office. Les vidéos sont déposées dans la boîte de réception TikTok du compte autorisé. FAM$ ne publie aucune vidéo : la publication éventuelle reste une action manuelle du titulaire du compte dans l'application TikTok.

4. Contenus

Le titulaire du compte est responsable des contenus déposés. Il doit respecter les Conditions d'utilisation et les Règles communautaires de TikTok.

5. Révocation

L'autorisation peut être retirée à tout moment dans les réglages de sécurité de l'application TikTok, ou depuis FAM$ via le point de révocation de l'API TikTok.

6. Absence de garantie

FAM$ est fourni en l'état, sans garantie de disponibilité.

7. Contact

Pour toute question, ouvrir un ticket (« Issue ») sur le dépôt GitHub qui héberge ce site.
